# Universal Extractor | math12393

A web-based extractor and creative studio for various file types, including archives, images, audio, and video.

## Introduction

The Universal Extractor is a versatile tool designed to extract and edit various file types. It supports extraction from archives like ZIP, TAR, APK, and IPA, as well as editing capabilities for images, audio, and video files.

## Features

*   Extract files from archives (ZIP, TAR, APK, IPA, XAPK, mobileconfig, RAR, EXE)
*   Edit images using Fabric.js
*   Trim audio and video files
*   Download extracted and edited files
*   Export multiple files as a ZIP archive

## Usage

Visit the Universal Extractor at [https://math12393.codeberg.page/Universal-Extractor/](https://math12393.codeberg.page/Universal-Extractor/) to start extracting and editing files.
